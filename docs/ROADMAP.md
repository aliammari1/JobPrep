# Roadmap

A rough, honest plan. It changes with feedback; open a [Discussion](https://github.com/aliammari1/JobPrep/discussions) to influence it. Items marked 🌱 are good first contributions.

## Now

- Burn down the Biome warning baseline (hook dependencies, array-index keys, accessibility warnings) and raise them back to errors. 🌱
- Grow test coverage beyond `src/lib` (API routes, CV builder). 🌱
- Hosted read-only demo with the seeded account.

## Next

- Resume parsing and ATS keyword scoring improvements.
- Interview answer history and progress over time on the dashboard.
- More languages for the UI and interview questions. 🌱
- Offline-first practice mode in the PWA.

## Later

- Shared practice sessions with a coach or peer.
- Plugin-style providers for code execution.
- Public API keys and webhooks.

## Done

See the [releases](https://github.com/aliammari1/JobPrep/releases) page and the generated `CHANGELOG.md` once the first release is cut.

Want to take something? Comment on the issue, or open one first for larger work. See [CONTRIBUTING.md](../CONTRIBUTING.md).
