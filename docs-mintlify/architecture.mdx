JobPrep is a Next.js 15 (App Router) app with a Prisma/PostgreSQL data layer,
Better-Auth authentication, the Vercel AI SDK for multi-provider AI, and a
separate Python container for the live interview avatar.

- **AI registry** resolves a `<provider>:<model>` id to a model — adding a
  provider is a 3-line change with no call-site edits.
- **API docs** are generated by `next-swagger-doc` from `@swagger` annotations
  and rendered at `/api-docs` (Scalar).
- The **Python avatar agent** is a long-running container workload, not a Worker.

See the full diagram and component breakdown in
[`docs/ARCHITECTURE.md`](https://github.com/aliammari1/JobPrep/blob/main/docs/ARCHITECTURE.md).
