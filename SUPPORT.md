# Getting help

| I want to… | Go to |
| --- | --- |
| Run JobPrep locally | [Setup guide](CONTRIBUTING.md#getting-started-web-app) and [common problems](CONTRIBUTING.md#common-setup-problems) |
| Understand how it works | [Architecture](docs/ARCHITECTURE.md), [Deployment](docs/DEPLOYMENT.md), [Product guides](docs-mintlify/) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/aliammari1/JobPrep/discussions) |
| Report a reproducible bug | [New issue](https://github.com/aliammari1/JobPrep/issues/new/choose) |
| Report a security problem | [Private advisory](https://github.com/aliammari1/JobPrep/security/advisories/new). See [SECURITY.md](SECURITY.md). |
| Ask about commercial use | Email the maintainer listed in [LICENSE.md](LICENSE.md) |

Before posting, search existing issues and discussions. A good question includes what you tried, what you expected, what happened, and your environment. Remove API keys, tokens, and personal data from anything you paste.

JobPrep is maintained by volunteers in their spare time. There is no guaranteed response time.
