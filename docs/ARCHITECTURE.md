# Architecture

JobPrep is a Next.js 15 (App Router) application with a Prisma/PostgreSQL data
layer, Better-Auth authentication, the Vercel AI SDK for multi-provider AI, and
a separate Python container for the live video interview avatar.

## High-level

```
                    ┌─────────────────────────────────────────────┐
                    │                Next.js 15 app                 │
  Browser ───────▶  │  App Router pages + 82 API route handlers     │
  Chrome ext ────▶  │  ─ /api/ai/coach   (provider-agnostic)        │
                    │  ─ /api/cv/*, /api/interviews/*, /api/stripe/*│
                    │  ─ /api/openapi, /api-docs (Scalar)           │
                    └───────┬───────────────┬───────────────┬──────┘
                            │               │               │
                   Better-Auth        Vercel AI SDK     Prisma Client
                   (Prisma adapter)   provider registry      │
                            │               │               ▼
                            │        ┌───────┴───────┐   PostgreSQL
                            │        │ Claude / GPT /│   (Hyperdrive
                            │        │ Gemini /Ollama│    on Cloudflare)
                            ▼        └───────────────┘
                     Stripe (billing)

   Live interview (real-time, NOT on Workers):
   Browser ⇄ LiveKit (WebRTC) ⇄ Python agent container ⇄ Simli avatar API
```

## Components

- **Web app (`src/app`)** — App Router UI + API route handlers. AI route
  handlers stream responses with the Vercel AI SDK.
- **AI registry (`src/lib/ai`)** — `providers.ts` resolves a `<provider>:<model>`
  id to a `LanguageModel`; `coach.ts` holds the coach system prompt + request
  schema. Adding a provider is a 3-line change (no call-site edits).
- **Auth (`src/lib/auth.ts`)** — Better-Auth with the Prisma adapter; passkeys,
  2FA, magic links, email OTP, organizations.
- **Data (`prisma/`)** — Postgres schema; client generated to
  `src/generated/prisma`.
- **Billing (`src/lib/stripe.ts`)** — lazily-initialised Stripe client (so the
  build doesn't require a key).
- **Chrome extension (`chrome-extension/`)** — imports LinkedIn profile data
  into the CV builder. Zipped into release assets on tag.
- **Python avatar agent (`functions/LiveKit Avatar Agent`)** — LiveKit + Simli
  avatar; managed with uv, tested with pytest, linted with ruff. **Container
  workload, not a Worker.**

## API documentation

The OpenAPI document is generated by `next-swagger-doc` from `@swagger` JSDoc
blocks on route handlers (`src/lib/openapi.ts`), served at `/api/openapi`, and
rendered interactively at `/api-docs` with `@scalar/nextjs-api-reference`.
Conceptual docs live in `docs-mintlify/` for publishing on Mintlify.

## Testing

- **Unit** — Vitest, coverage scoped to currently-tested modules (utils,
  subscription plans, ollama JSON cleaning, the AI provider registry, coach
  schema) with a ratcheting threshold floor.
- **E2E** — Playwright smoke flows (landing, sign-in form, CV builder) that
  don't require a backend.
- **Python** — pytest/ruff via uv for the avatar agent.
